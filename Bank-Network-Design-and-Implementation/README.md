# Bank Network Design and Implementation

## Project Overview

This project presents a four-floor enterprise bank network designed and implemented using Cisco Packet Tracer. The network is designed to provide secure, scalable, and efficient communication between different departments.

## Network Design

The network follows a hierarchical network architecture with multiple switches, routers, VLANs, servers, wireless access points, PCs, and printers.

### Departments & VLANs

* Management — VLAN 10
* Research — VLAN 20
* Human Resource — VLAN 30
* Marketing — VLAN 40
* Accounts — VLAN 50
* Finance — VLAN 60
* Logistics — VLAN 70
* Customer Service — VLAN 80
* Guest — VLAN 90
* Administration — VLAN 100
* ICT — VLAN 110
* Server Room — VLAN 120

## Technologies & Concepts

* Cisco Packet Tracer
* IPv4 Addressing & Subnetting
* VLAN
* Inter-VLAN Routing
* OSPF
* DHCP
* Wireless Networking
* SSH
* Port Security
* Sticky MAC
* HTTP Server
* Email Server

## Key Features

* Department-based VLAN segmentation
* Dynamic routing using OSPF
* DHCP server configuration
* Wireless network connectivity
* Secure remote access using SSH
* Switch port security using Sticky MAC
* Inter-VLAN communication
* Dedicated server room
* Connectivity testing between network devices
