# Bank Network Design and Implementation

## Project Overview

This project presents a four-floor enterprise bank network designed and implemented using Cisco Packet Tracer. The network is designed to provide secure and efficient communication between different departments.

## Network Design

The network uses a hierarchical architecture with routers, switches, VLANs, servers, wireless access points, PCs, and printers.

### VLANs & Departments

| VLAN | Department       |

## Key Features

* Department-based VLAN segmentation
* Dynamic routing using OSPF
* DHCP server configuration
* Wireless network connectivity
* Secure remote access using SSH
* Switch port security using Sticky MAC
* Inter-VLAN communication
* Dedicated server room
* Network connectivity testing
